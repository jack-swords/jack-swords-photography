Adding it to Outlook
  1. Click Copy signature.
  2. New Outlook / Outlook on the web: Settings → Accounts → Signatures → New signature → paste (Ctrl/Cmd+V) → Save.
  3. Classic Outlook (Windows): File → Options → Mail → Signatures… → New → paste into the editor → OK.
  4. Outlook for Mac: Outlook → Settings → Signatures → + → paste → Save.
  5. Pick it as the default for new messages and replies.

Classic Outlook on Windows can't show embedded images in signatures. For that app, fill in the image folder URL above first.

After saving, send yourself a test email and view it in dark mode. Some Outlook editors strip the logo-swap code. If yours does, the dark logo with its fine outline shows instead.
